# 🧠 Task Manager API (FastAPI)

This is my first backend project using **FastAPI**, focused on creating a simple RESTful API for task management. It includes basic **CRUD operations** to help me understand how backend logic works.

> ⚠️ Note: This project is not intended to be showcased as a portfolio piece. I built and uploaded it mainly to practice modularization, version control, and backend flow.

---

## 🚀 Features

- Add, update, delete, and retrieve tasks.
- Built with FastAPI and Python.
- Modular code structure (e.g., routers, models, logic).
- Designed for local use and learning purposes.

---

## 🛠️ Running the Project

```bash
# Clone the repo (if not already)
git clone https://github.com/Albert-Michael/Task_Manager_API.git
cd Task_Manager_API

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt

# Run the app
./run.sh
